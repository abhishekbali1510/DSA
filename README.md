# 🧠 Daily DSA Problem Solving & Revision Journal

A structured repository tracking my daily Data Structures & Algorithms practice. Instead of just storing code, this repo focuses on **core intuition, edge cases, algorithmic patterns, and trade-offs** to serve as an effective revision notebook for technical interviews.

---

### 🎯 Objectives
- **Consistency:** Solve and analyze at least one problem daily.
- **Pattern Recognition:** Group problems by core patterns (Sliding Window, Two Pointers, Trees, DP) rather than isolated tricks.
- **Active Recall:** Document the "aha!" moment, common pitfalls, and edge cases for rapid spaced-repetition review.
